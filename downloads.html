Downloads

All software described on this website is free and open source. Every repository is on GitHub under the MIT License. You can download, use, modify, and redistribute everything without restriction.

BeehiveOfAI — The Level 1 marketplace website. A Flask application with a SQLite database that connects Workers, Queens, and Beekeepers. Handles user registration, job submission, task distribution, and result delivery. Supports SMS verification via Twilio and deployment through Cloudflare Tunnel.

🔗 github.com/strulovitz/BeehiveOfAI

HoneycombOfAI — The Level 1 client software. Turn your computer into a Worker Bee, Queen Bee, or Beekeeper. Features a native PyQt6 GUI with dark theme, supports five AI backends (Ollama, LM Studio, llama.cpp server, llama.cpp Python, vLLM), and includes a Demo Mode for trying without installing AI models.

🔗 github.com/strulovitz/HoneycombOfAI

KillerBee — The hierarchical hive website/server. Manages unlimited-depth hierarchies: RajaBee → GiantQueens → DwarfQueens → Workers. Includes the Buzzing calibration system for proportional work distribution and smart_splitter for flexible AI output parsing.

🔗 github.com/strulovitz/KillerBee

GiantHoneyBee — The hierarchical client software. RajaBee, GiantQueen, DwarfQueen, and Worker clients. All communicate exclusively through the KillerBee website's REST API. No direct communication between bees. Unlimited scaling by adding machines.

🔗 github.com/strulovitz/GiantHoneyBee

StrulovitzGhost — AI layered image generation pipeline. Pepper's Ghost-style visual illusions created through AI-decomposed transparent layers.

🔗 github.com/strulovitz/StrulovitzGhost
