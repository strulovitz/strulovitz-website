# THE INBOX
# =========
#
# WHAT THIS FILE IS
# Where Nir puts the links for stories he wants written. This is the only place
# a story ever comes from: the machine never decides for itself what is worth
# covering (DECISIONS.md decision 17 - the magazine covers "what is the most
# interesting subjectively to my audience", which is a human judgement).
#
# HOW TO ADD A STORY
# Write a line starting with STORY and a short title, then the links, one per
# line. Anything after a # is a note for humans and is ignored. Then run:
#     cd pipeline && uv run stages/make_story.py
# Stories already made are skipped, so this file can keep growing and the
# command is always safe to re-run.
#
# THE RULE THAT CANNOT BE BROKEN
# Two independent sources minimum, or the story is not written at all
# (DECISIONS.md decision 13). Nir: "if a story is only from one source, even if
# it is the most amazing story, like new aliens came and handed us AGI, i cannot
# publish it, because i can get sued and lose all my money."
