AI benchmark

An encyclopedia idea, explained by this edition wherever the stories leaned on it.

As explained in 2026-08-13-grok-4-6

An AI benchmark is a fixed, standardised set of tasks that different models can be set against, so their abilities can be compared on the same questions — the way a class sits the same exam. Some benchmarks are automatic: a coding model is given bugs to fix or programs to build and pass-or-fail tests decide the score. Others are graded by people, for example by giving models real projects from real jobs and having experienced humans judge the results. Composite indices average many benchmarks into a single number for a leaderboard. Benchmarks matter because buyers use them as a first filter between competing models. They also deserve caution: a model can score well because near-copies of the test leaked into its training data, companies naturally publish the charts that flatter them, and a high score does not guarantee a model feels capable in daily use. Experienced reviewers treat benchmarks as evidence, not verdicts, and weigh them against hands-on time.
